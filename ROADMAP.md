# Development Roadmap

This roadmap keeps the repository useful for teaching while maintaining a defensible standard for scientific analysis.

## Phase 1 — Core scientific Python

- Environment setup and notebook checks
- NumPy arrays, indexing, units, and vectorised calculations
- Tabular data handling with pandas
- Clear plotting with Matplotlib
- Curve fitting, residual analysis, and uncertainty
- Exercises with worked solutions released separately

## Phase 2 — Physics and materials workflows

- Current–voltage analysis
- Resistance, conductivity, and sheet-resistance calculations
- Photodetector responsivity and time-response analysis
- Optical and spectroscopic data processing
- Materials-characterisation examples
- Transparent comparison of alternative fitting models

All example data will be labelled as measured, simulated, or synthetic. Proprietary, student-owned, unpublished, or collaborator-owned data will not be uploaded without permission.

## Phase 3 — Teaching and reuse

- Short instructor notes
- Learning outcomes and prerequisite maps
- Auto-checked exercises where appropriate
- Browser-based notebook launch options
- Versioned tutorial releases
- Links between selected tutorials and recorded lectures

## Release criteria

A tutorial is ready for release when it:

- runs from a clean environment;
- identifies its data source;
- states assumptions and units;
- distinguishes calculation from interpretation;
- includes at least one validation or reasonableness check;
- gives attribution for reused material; and
- has been reviewed for scientific and typographical errors.

## Current milestone

The repository foundation and first executable tutorial are being established. Domain-specific research workflows will follow after the core notebooks are stable.
