# Contributing

Corrections and carefully scoped contributions are welcome. The repository is intended for scientifically defensible teaching material, so clarity, provenance, and reproducibility take priority over the number of notebooks.

## Before contributing

- Open an Issue before preparing a substantial new tutorial.
- State the proposed learning objective, audience, and required background.
- Confirm that you are authorised to share all code, figures, and data.
- Do not upload unpublished research data, confidential laboratory records, student work, or collaborator-owned material without written permission.

## Tutorial requirements

A contribution should:

- distinguish measured, simulated, and synthetic data;
- identify units in variable names, tables, and figures;
- state assumptions and limits of interpretation;
- run from the documented environment;
- avoid hidden manual processing steps;
- include at least one check of the result;
- cite external methods, datasets, and adapted code; and
- use concise explanatory text suitable for students.

## Suggested notebook structure

1. Title and context
2. Learning objectives
3. Imports and environment check
4. Data source and units
5. Analysis
6. Validation or residual checks
7. Physical interpretation
8. Exercise or extension
9. References, where required

## Submitting a change

1. Create a focused branch.
2. Make one coherent change.
3. Restart the notebook kernel and run all cells in order.
4. Check that outputs contain no personal paths, credentials, or confidential data.
5. Submit a pull request explaining what changed and how it was verified.

Minor corrections can be reported through GitHub Issues.
