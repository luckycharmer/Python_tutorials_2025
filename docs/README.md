# Professional portfolio staging

This folder contains a lightweight, static professional portfolio for Junaid Ali.

## Why this exists

The site is designed to present one coherent professional narrative:

**Scientist → Research leader → Technology translator → Emerging science/technology governance**

It deliberately avoids:
- claiming established AI-governance expertise;
- inflated metrics or unverified impact claims;
- generic skill bars, badges, or decorative GitHub statistics;
- confidential, student-owned, collaborator-owned, unpublished, or patent-sensitive material.

## Intended deployment

Preferred long-term deployment: a dedicated GitHub Pages repository (ideally with a professional custom domain).

This staging copy lives inside the Scientific Python Tutorials repository only because a separate website repository has not yet been created through the connected GitHub tools.

## Maintenance checks

Before publishing:
1. Confirm current academic title and institutional roles.
2. Add a current CV only after reviewing it for public disclosure.
3. Add LinkedIn only when the exact canonical URL is confirmed.
4. Add selected publications with DOI links rather than a long publication dump.
5. Keep AI/governance wording evidence-based and update it as genuine work is produced.
6. Recheck all institutional links after role changes.
7. Never upload unpublished or proprietary research data merely to make the portfolio appear fuller.
