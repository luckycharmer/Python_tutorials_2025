# Episode 2 fact sheet — The bond is a spring

**One idea:** a bond is like a spring that always rings at the same note, green laser light comes back slightly red by exactly that note, and heavier atoms ring lower.

Off screen but in the notebook: spring stiffness k = μ(2πcωₑ)² = 575 N/m for H₂ and 576 N/m for D₂ (Atkins' *Physical Chemistry* table of diatomic constants lists 575 N/m for H₂).

**Trap checks**

- **Infrared.** H₂ and D₂ have no electric dipole, so ordinary infrared absorption does not see their vibration. Very weak quadrupole infrared lines do exist (Herzberg 1949; seen in planetary atmospheres) and pressure-induced absorption occurs in dense gas. So the script says "infrared barely sees it", not "infrared can't see it". Raman scattering is allowed and is the standard way to see it.
- **Which frequency?** The Raman shift is the v = 0 → 1 spacing (4161 cm⁻¹), not the harmonic constant ωₑ (4401 cm⁻¹). On screen only 4161 cm⁻¹ and the frequency derived from it appear. The stiffness 575 N/m comes from ωₑ, so it is kept off screen to avoid mixing the two.
- **"Fixed note".** Every H₂ molecule in v = 0 has the same vibrational spacing. Rotation splits the Raman Q branch into lines a few cm⁻¹ apart (Q(1) is at 4155 cm⁻¹), invisible on the video's nm ruler. "Same note" is fair at this resolution.
- **Green in, red out.** Most scattered light is unchanged (Rayleigh). Only a tiny fraction is Raman shifted. The red peak in the picture is drawn enlarged and labelled so. At 25 °C only 2 × 10⁻⁹ of H₂ is already in v = 1, so the blue-shifted (anti-Stokes) line is negligible; we show only the Stokes line.
- **Heavier is slower, but not exactly √2.** Same electrons, same spring (575 vs 576 N/m). The reduced mass doubles (×1.998), so a perfect spring would be √2 = 1.41 times slower. The measured ratio is 1.39 because the real bond is not a perfect spring (anharmonicity is larger for H₂). The script says "close to √2", not "exactly".
- **Wavelengths.** 532 nm is nominal; Raman arithmetic uses vacuum wavenumbers. Air/vacuum differences are about 0.2 nm, below the precision shown.
- **The picture.** A single ball on a spring stands for the reduced mass (the two atoms swinging against each other). The wave the spring draws is slowed by about 1.2 × 10¹⁴ times. The D₂ wave uses the same slowdown, so the two speeds on screen are in the true ratio.
